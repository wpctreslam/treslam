3. 联机模式

复用你已有的 Supabase 项目，无需新增服务器/域名/证书，手机流量天然可达。
一次性准备：① SQL Editor 粘贴运行 deploy/supabase-quiz.sql； ② 把 index.html 上传到公开 Storage 桶（或用任意静态托管）。
anon key 是公开密钥（设计上就会下发到浏览器）；真正的安全边界是 SQL 里把表权限收回、只留 RPC。
推荐方式。在电脑上运行 node server.js，手机与电脑连同一 Wi-Fi， 直接用手机浏览器打开终端里显示的地址（形如 http://192.168.1.10:3000）， 此栏会自动填好，无需手动输入。
公网对战：把 server.js 部署到任意云服务器，填 wss://你的域名/ws。
零配置，仅用于测试界面与流程。数据只在当前这台设备的当前浏览器内共享： 打开多个标签页/窗口，分别用不同昵称加入同一房间号即可看到实时同步效果。
多台手机真实对战请选「服务器联机」或「Firebase」。
无需自建服务器：Firebase 控制台 → 新建项目 → Realtime Database → 创建数据库（测试模式）→ 项目设置 → 你的应用 → Web → 复制 firebaseConfig 粘到上面。
注意：Firebase 在中国大陆网络下通常无法访问，国内请优先用「服务器联机」。
